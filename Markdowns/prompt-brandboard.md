Título del documento: Brandboard VACA – Sistema de Identidad Visual Institucional

Contexto y condición indispensable para NotebookLM:
Este documento es la base para generar una presentación ejecutiva de 8 diapositivas sobre el Brandboard de "VACA".

CONDICIÓN OBLIGATORIA: La marca VACA YA POSEE un logotipo definido y existente (tipografía principal: Anderson Grotesk, con su respectivo Sello Ceremonial e Isotipo móvil). NO se debe generar ni proponer un nuevo logotipo. El objetivo de esta presentación es INTEGRAR y COMBINAR ese logotipo existente con la nueva estética "Clasicismo Cívico Celadón", demostrando cómo convive armónicamente con la paleta cromática, las tipografías secundarias, la iconografía arquitectónica y el tratamiento fotográfico.

La dirección visual prohíbe estrictamente la estética Y2K, neón, glitch, rosa eléctrico o elementos sensacionalistas. La presentación debe ser profesional, funcional y servir como guía gráfica unificada para diseñadores, desarrolladores y aliados.

Título: Gobernanza y Control de Calidad Visual

PRÁCTICAS CORRECTAS (DO'S):

Usar siempre las versiones oficiales del logotipo VACA (positivo, negativo, sello, isotipo).

Mantener contraste WCAG AA. Usar iconos con etiquetas claras. Aplicar monoespaciada para códigos.

PRÁCTICAS PROHIBIDAS (DON'TS):

NUNCA modificar, estirar ni recolorear el logotipo VACA existente fuera de la paleta permitida.

NUNCA usar neón, glitch, glassmorphism o Y2K. NUNCA rodear el logo de columnas griegas literales.
